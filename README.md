CSS Fundamentals 🎨

📌 About the Project

This project is created to practice the fundamentals of CSS and learn how to design a clean, modern, and attractive website.

🎯 What I Learned

- Basic CSS styling
- Colors and backgrounds
- Text styling
- CSS selectors
- Styling cards and containers
- Improving website readability
- Creating a modern UI design

🎨 Design Choices

1. Purple Color: I chose purple because it represents creativity, innovation, and learning.
2. Light Background: I used a light background to make the website look clean and comfortable to read.
3. White Cards with Purple Accents: I used white cards with purple accents to create a modern design with good readability.

🛠️ Technologies Used

- HTML5
- CSS3
- Visual Studio Code

📚 Purpose

The purpose of this project is to strengthen my CSS fundamentals and improve my web development skills.
